**SHADOW SYSTEM**

1\. **Soft shadow**  
X offset: 1px  
Y offset: 6px  
Blur radius: 30px  
Spread: 0px  
Colour: \#16A34A1F  
Opacity: approximately 12.2%

Purpose: Subtle depth for cards and surfaces that should feel gently lifted without drawing attention away from the content.

2\. **Medium shadow**  
X offset: 4px  
Y offset: 6px  
Blur radius: 24px  
Spread: 0px  
Colour: \#16A34A2E  
Opacity: approximately 18.0%

Purpose: More visible elevation for interactive cards, floating elements, or components that need stronger separation from the background.

3\. **Hard shadow**  
X offset: 6px  
Y offset: 10px  
Blur radius: 20px  
Spread: 0px  
Colour: \#16A34A33  
Opacity: approximately 20.0%

Purpose: Stronger directional depth for elements that need to stand out more clearly from surrounding surfaces.

**WHY USE A BRAND-COLOURED SHADOW?**  
A shadow built from Workn's green carries a subtle colour cast, helping elevated components feel connected to the brand rather than visually neutral. A black shadow tends to create a more neutral grey effect, while a green shadow can make the interface feel warmer and more cohesive, especially against pale green surfaces.
